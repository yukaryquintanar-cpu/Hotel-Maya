# 🏨 Hotel Maya Bay

Sistema de Reservas y Logística de Transporte

Plataforma web para la gestión de reservas de habitaciones y coordinación de traslados al aeropuerto del Hotel Maya Bay.

## 📋 Descripción

Sistema diseñado para automatizar el agendamiento doble de hospedaje y transporte, permitiendo a los huéspedes gestionar desde una sola interfaz tanto su estancia en el cuarto como su traslado seguro al aeropuerto. El sistema garantiza que no existan cruces de fechas ni sobrecupo en las unidades de transporte.

## ✨ Características

- Gestión de disponibilidad y reservas de 40 habitaciones
- Coordinación de traslados al aeropuerto en 3 unidades de transporte
- Sistema de agendamiento doble (hospedaje + transporte) en una sola interfaz
- Validación automática para evitar cruces de fechas y sobrecupo
- Autenticación de usuarios para el control de acceso

## 🛠️ Tecnologías utilizadas

**Frontend:**
- HTML5
- CSS3 nativo
- Bootstrap 5.3 (diseño responsivo)
- JavaScript Vanilla (ES6 Modules)

**Backend y Base de Datos:**
- Firebase Authentication (control de acceso)
- Cloud Firestore (base de datos NoSQL)
- Firebase Hosting (despliegue)

## 🚀 Instalación y uso

1. Clona este repositorio:
```bash
   git clone https://github.com/yukaryquintanar-cpu/Hotel-Maya.git
```
2. Entra a la carpeta del proyecto:
```bash
   cd Hotel-Maya
```
3. Configura tus credenciales de Firebase en el archivo de configuración correspondiente
4. Abre `index.html` en tu navegador o despliega con Firebase Hosting
